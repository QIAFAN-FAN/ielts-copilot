## 这是什么

刷雅思真题时，你会反复做这几件事：查一个词、看这题为什么选 C、搞清这句话的语法、想作文该怎么写。
这些事分散在词典 App、网页搜索和聊天窗口之间，打断做题节奏。

这个扩展把它们收进浏览器侧边栏：**划一下要查的内容，或者点一下「抓取本页」，剩下的交给它。**

技术上是 Chrome MV3 扩展，纯前端（无后端、无中继服务器），调用 **DeepSeek API**，Key 由使用者自己填。

> **只支持 DeepSeek。** 因为它便宜、中文好，而且支持图像理解（小作文图表可以直接给图）。
> 换其他 OpenAI 兼容网关理论上也能用，但没有做过兼容性测试。

## 主要功能

### 划词翻译（右键也能用）

在任意网页划选英文（也支持纯中文划词走中译英），旁边会冒出一个小圆点，点开是气泡：

- **译文** + 一句「这句话的关键结构」说明 + 最多 4 个雅思高频生词
- 译文旁有 **📋 复制按钮**（复制中文 / 英文 / 英+中，可在设置里选）
- 每条生词后面有 **📌 收藏为术语** 按钮
- 可以 **📌 固定** 气泡位置，之后划别的词直接翻到同一个框里
- 气泡 **透明度可调**（15% ~ 100%，鼠标移上去恢复不透明）—— 不想被别人看到屏幕时用得上

### 阅读题解析

在题库页面点「抓取本页」，它会自动识别页面的左右两栏（原文 / 题目），分别填进两个框，然后给出：

题目速览 → 答案表 → 逐题解析（含原文定位句、同义替换对照、为什么排除其他选项）→ 高频同义替换清单 → 生词与长难句 → 这类题的解题步骤

### 听力题分析

抓取本页的题目，它会判断题目出处（哪套剑桥雅思、哪个 Section）、给出参考答案和把握程度、讲每题的听觉陷阱（转折词、数字混淆、拼写字母听辨），还能生成搜索关键词去网上核对答案。

### 写作思路 / 作文批改

两套提示词：一套给思路 + 分段结构 + 高分表达 + 完整范文；一套按雅思四项评分标准逐段批改，给预估分数和升级版改写。

**小作文可以加图片**：图表可以直接上传、截取当前画面、抓取页面里的大图，或者**拖进来 / 复制粘贴**。

### 深入精讲

气泡里点「深入精讲」，侧边栏会对这段文字做语法拆解和考点分析。

## 安装（约 2 分钟）

这个扩展**没有上架 Chrome 商店**，需要以「开发者模式」加载：

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`），**解压**
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 打开右上角的 **开发者模式**
4. 点 **加载已解压的扩展程序**，选择**包含 `manifest.json` 的那一层文件夹**
   > ⚠️ 常见的错：如果解压后是 `雅思助手-main/雅思助手/` 这样的嵌套结构，要选**里面那层**（有 `manifest.json` 的）
5. 点浏览器工具栏的扩展图标 → 打开侧边栏

### 填 API Key（只做一次）

1. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册，在「API Keys」创建一个 Key（形如 `sk-...`）
2. 右键扩展图标 → **选项**（或侧边栏右上角的 ⚙）
3. 填进「API Key」，点「测试连接」确认可用，再点「保存设置」

> DeepSeek 的余额与 OpenAI 不通用，需要单独充值。日常做题的使用成本很低 —— 大量短句会走内置离线词表，完全不花钱。

## 怎么用

| 场景 | 操作 |
| --- | --- |
| 查单词 / 句子 | 划选 → 点小圆点 → 看气泡 |
| 分析阅读题 | 题库页面点「抓取本页」→ 侧边栏「阅读」→ 开始分析 |
| 分析听力题 | 同上，「听力」标签 |
| 练写作 | 把题目贴进「写作思路」 |
| 批改作文 | 把作文贴进「作文批改」 |
| 只想弄清某一句 | 划选 → 气泡 →「深入精讲」 |

抓取不准的时候，两个框旁边都有「用选中文字」按钮：在网页上手动划选后点它即可。

## 它是怎么帮你省钱的

这是本项目最花心思的部分。**省 token 不是靠少调用，而是靠「不该调的时候真的不调」**：

**1. 两段式翻译 —— 先出结果，再精译**

划词时先只用本地词表算一遍（几乎瞬时），立刻显示出来；如果这次结果不够用，气泡里显示「AI 精译中…」并自动补一次 AI 调用。**所以你不需要干等模型几秒钟。**

**2. 2400 条内置离线词表**

含雅思学术词、小作文图表词、熟词僻义、常用短语。**单个词、单个短语永远不调 AI**，零 token。

智能档只有在**四个条件同时满足**时才用逐词直译：覆盖率 ≥95%、实词 ≤25 个、一个生词都没有、句子里没有从句。任何一条不满足就老老实实调 AI —— 因为逐词直译出来是断的，不如不用。

**3. 术语库：让 AI 按你指定的意思翻**

`bank` 是「银行」还是「河岸」，`address` 是「地址」还是「处理」—— 离线词表只能告诉你有哪些意思，判断不了这句该取哪个。

把词加进术语库（或点气泡里的 📌），翻译时会要求模型**必须按你指定的译名翻**。
内置了一批**无歧义**的专业术语和固定搭配（`biodiversity`、`level off`、`account for`…）。

> 这里刻意**不收熟词僻义**：术语库是「只要这个词出现就强制生效」的硬约束，而 `will` / `might` / `last` / `right` 这些词在雅思文章里绝大多数用的是**常见义**。硬塞僻义会把默认译文带偏，而且你很难联想到是术语库干的。

**4. 词汇自学习：翻得越多，越省**

AI 翻译时会顺手返回这句里生词的词级释义。同一个词被释义 **3 次且完全一致**，就自动收进离线词表 —— **以后含这个词的句子离线就认识，直接零 token。**

为了防止学错词义，有四道防线：

1. 离线词表里**已经有**的词一律不学（挡住绝大多数常见多义词）
2. 只要出现过**两种以上**释义，说明这词有歧义（`bank` 河岸/银行），**永不自动收录**
3. 学到的词只在**内置词表查不到**时才用，永远不覆盖内置释义
4. 设置页里**可见、可搜、可逐条删除、可一键清空**

**5. 三层缓存**

内存 → `chrome.storage` → 单次会话。同一句话翻过一次就不再花钱；改了术语库会自动让旧缓存失效（因为译名可能变了）。

**6. 联网检索可控**

分析阅读/听力前可以联网核对题目出处。官方搜索更准，但会产生一整轮模型调用的开销；浏览器方式免费。可以关掉。

## 代码结构

无构建步骤，改完在 `chrome://extensions/` 刷新即可，纯 JavaScript ES Module。

```
manifest.json              MV3 清单（版本号在这里）
background.js              service worker：消息路由、抓取编排、图片抓取
content/
  content.js               注入网页：划词气泡 / 抓取页面文本·表格·图片
sidepanel/
  panel.html|js|css        主工作台（阅读 / 听力 / 写作 / 批改 / 精讲 五板块）
options/
  options.html|js|css      设置页（含术语库与词汇学习管理）
lib/
  store.js                 设置项默认值与迁移
  deepseek.js              API 调用、重试、流式解析
  prompts.js               各场景提示词
  translate.js             翻译调度：两段式、智能档判定、三层缓存
  dict.js + dict-data.js   离线词表（2365 条）与逐词直译
  glossary.js + glossary-data.js  术语库 + 词汇自学习
  markdown.js              Markdown 渲染（含嵌套列表）
  websearch.js             浏览器搜索兜底
  dssearch.js              DeepSeek 官方 Web Search（Anthropic 兼容端点）
```

**几个值得注意的实现细节**（如果你要读代码）：

- 抓取页面时**绝不用整页兜底**：认不出角色就留空并提示手动划选，这样题目框永远不会混进原文
- 区块去重用**最短块优先**（保留最小包含块）后恢复原顺序 —— 否则大容器会把细碎的题目块吞掉
- 划词气泡对「元素已被页面重渲染摘掉」有守卫，不会因为 SPA 重渲染而永久失效
- 流式渲染的定时器在切板块时会被取消，避免旧板块的内容画进新板块

## 隐私

- **API Key 只存在你自己浏览器的 `chrome.storage.local` 里**，不上传任何服务器
- 请求**只发往你填写的接口地址**（默认 `api.deepseek.com`），没有中转服务器、没有统计埋点
- 划选的文字会随翻译请求发给 DeepSeek（这是调用 API 的必然结果），本扩展不额外收集任何数据
- 所有缓存、草稿、词表、术语都只存在本地，卸载扩展即全部清除

## 已知限制

诚实地列出来，避免你踩坑：

- **没有上架商店**，需要开发者模式加载；每次更新要手动点刷新
- **只支持 DeepSeek**，没有做其他模型的兼容性测试
- **划词气泡在部分网站上位置会偏**：如果页面内容在 iframe 里，气泡只能显示在那个小区域内（右上角会有「⧉ 框架内」提示）
- **页面重渲染后可能需要刷新**：个别 SPA 站点清空页面时，划词可能短暂失效，刷新网页即可恢复
- **抓取依赖版面特征**：如果题库站点结构特殊，可能只识别出一部分，这时用「用选中文字」手动划选更可靠
- **听力实时字幕没有实现**：DeepSeek 没有语音识别接口，做字幕需要另接语音识别服务或本地模型，成本和复杂度都很高
